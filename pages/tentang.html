Tentang Proyek

Website Dashboard Admin Statis

Proyek pembelajaran Frontend Dasar.

Tujuan Proyek

Website ini dibuat untuk memenuhi tugas mata pelajaran Frontend Dasar kelas XI (PPLG) 3. Proyek ini melatih kemampuan menyusun struktur HTML dan mengatur tampilan menggunakan CSS Flexbox serta CSS Grid.

Teknologi yang Digunakan

  • HTML untuk struktur halaman website.
  • CSS untuk warna, tata letak, dan desain responsif.

Pembagian Tugas Kelompok

UI/UX Designer & Content Writer

Membuat rancangan halaman, menentukan warna, dan menyiapkan konten website.

HTML Programmer & CSS Programmer

Membuat struktur HTML5, styling CSS, tata letak, dan tampilan responsif.
